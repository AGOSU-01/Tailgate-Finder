# Tailgate Finder

A Vite + React + TypeScript prototype for a game-day marketplace around Ohio Stadium.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal. The current prototype includes a searchable tailgate directory, filter tabs, selectable map pins, join-request feedback, and a host listing form.

## Build

```bash
npm run build
```

This is a class-pitch prototype. Listing data and map geometry are local demo data and can later be replaced with a database, geocoding provider, payments, and authentication.
